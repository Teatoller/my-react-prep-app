# React Practice Sandbox

A fun React sandbox for practicing UI concepts and testing code patterns. This project is built with React, TypeScript, Vite, and React Router.

## Clone and Run

```bash
git clone https://github.com/Teatoller/my-react-prep-app.git
cd my-react-prep-app
npm install
npm run dev
```

Open the app at `http://localhost:5173`.

## What you can do here

- Experiment with React components
- Practice hooks, form handling, and state management
- Explore routing with React Router
- Test localStorage persistence and validation

## Build for Production

```bash
npm run build
```

## Notes

- This repo is intended as a code practice playground.
- Use it to try out new React ideas and learn by building.
